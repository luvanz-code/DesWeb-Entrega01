# DesWeb-Entrega01
# 💧 ONG Água Limpa para Todos
### 📋 Entrega 01: Estrutura e Conteúdo (HTML Semântico)

Este repositório contém a entrega inicial do projeto do website institucional para a ONG "Água Limpa para Todos". Esta primeira fase foi focada integralmente na **estruturação do conteúdo em HTML5** e na definição da navegação principal.

## 🎯 Objetivo da Entrega 01

O objetivo desta etapa foi criar a fundação do website, garantindo que a estrutura do documento seja **semântica, acessível e completa** em seu esqueleto básico, antes da aplicação de estilos (CSS) e funcionalidades dinâmicas (JavaScript).

## 📁 Estrutura do Arquivo `index.html`

O arquivo `index.html` define a página inicial e inclui as seguintes seções estruturais:

* **`<head>`:** Configuração de metadados, *charset*, *viewport* e *title*.
* **`<header>`:** Contém o logotipo (título) e a navegação principal (links para Início, Projetos e Participe).
* **`<main>`:** Área de conteúdo principal, organizada nas seções:
    * *Hero Section*: Chamada principal.
    * *Mission Section*: Detalhes sobre o propósito da ONG.
    * *Impact Section*: Números e métricas de impacto.
* **`<footer>`:** Informações de contato, endereço e direitos autorais.

> **Status:** O site atual é um **MPA (Multi-Page Application)**, com links para páginas futuras (`projetos.html`, `cadastro.html`) que serão desenvolvidas nas próximas etapas.

## 📌 Requisitos de Versionamento (Git/GitHub)

O desenvolvimento desta entrega seguiu as boas práticas de versionamento:

* **Commits Semânticos:** Uso de prefixos como `feat:`, `chore:`, etc.
* **Branching:** Uso de *branches* de desenvolvimento e *feature* para isolar e revisar o código.
* **Issue Tracking:** Utilização de Issues e Milestones para planejamento e rastreamento das tarefas.
